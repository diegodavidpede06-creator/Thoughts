---------------------------------------------------------------------------------------------

PROMPT LARAVEL

Necesito desarrollar un pequeño sistema web para compartir pensamientos y notas.

El sistema debe permitir que los usuarios:

Se registren, inicien sesion, cierren sesion, publiquen notas, pensamientos o textos, visualicen las publicaciones de otros usuarios, consulten sus propias publicaciones.

El sistema debe tener una base de datos sencilla con las tablas necesarias

cada publicacion debe tener, usuario que la publico, titulo, contenido, fecha de creación.

TECNOLOGIAS:

Laravel 13, PHP 8.4, SQLite, MVC, Blade, CSS y JavaScript propios.

No utilizar librerias externas de autenticacion.

DISEÑO:

Crear una interfaz sencilla y moderna


El sistema debe contar con:

pagina de inicio, registro, inicio de sesión, dashboard, formulario para crear publicaciones, lista de publicaciones, opcion para cerrar sesion.

BASE DE DATOS:

Crear las migraciones necesarias y generar la base de datos SQLite.

Tambien crear un seeder con algunos usuarios y publicaciones de prueba.

ENTREGA:

Desarrollar el proyecto paso a paso en este orden:

1. Estructura de carpetas y archivos.
2. Diseño de la base de datos.
3. Migraciones.
4. Modelos.
5. Controladores.
6. Middleware/autenticación.
7. CSS.
8. JavaScript.
9. Vistas Blade.
10. Rutas.
11. Seeder.
12. Instrucciones para ejecutar el proyecto.

El proyecto debe mantenerse pequeño, sencillo y enfocado únicamente en los requisitos solicitados.
